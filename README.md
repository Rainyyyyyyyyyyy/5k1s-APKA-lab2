# 5k1s-APKA-lab2
5 курс 1 семестр Аппаратная реализация криптоалгоритмов лаба 2  
---  
Задание:  
1. придумать автомат Мура, в противном случае - автомат Мили. Нарисуйте его диаграмму.
2. Условия:
   • разрядность входа автомата равна 8 битам, а разрядность выхода - 1 биту
   • выход должен принять значение 1, когда на вход поступило Ваше имя (латинскими буквами в кодировке ASCII)
3. Описать конечный автомат на SystemVerilog.
4. Написать для него тестбенч, выполняющий обход графа переходов, т.е. все имеющиеся переходы из одного состояния в другое.
5. Проверка правильности работы должна выполняться автоматически (assert).
6. Запустить симуляцию и визуально убедиться по временной диаграмме (вейвформе, waveform), что конечный автомат реализован правильно. Подсказка: можно увидеть подаваемые буквы, нажав ПКМ на название сигнала на временной диаграмме и выбрав Data Format -> ASCII. 6. Создать проект в Gowin EDA, добавить в него файл с описанием конечного автомата.
7. Выполнить синтез, изучить схематику, посмотреть затраченные ресурсы (Resource Usage Summary) типов Register и LUT, изучить их описание в документе.
